Branches

How can other people contribute to the project?

Other people can contribute to a GitHub project by being added as collaborators, allowing them to accsess the repo make pull requests and review code

Why is Branching Necessary

Branching allows developers to work on different features without affecting the main branch directly. This makes it easier for multiple people to work in one project and review changes

The Git commmands necessary for branches

(git switch -c branch-name) creates a branch.

(git switch main) switches to the main branch.

(git merge branch-name) merges a branch.

(git branch -d branch-name) deletes a branch.
