Git commands

Create a project locally

Open your terminal in VS Code and navigate to the folder where you want to create the project. mkdir — creates a new directory. cd — moves into that directory. Initialize Git: git init. This turns the folder into a local Git repository. Create your project files, for example index.html, style.css, and script.js. Check the current status: git status. Stage your files and make your first commit: git add. git commit -m "Initial commit"- git add . — stages all new and modified files in the current directory.- git commit -m "Initial commit" — saves a snapshot of the staged changes with a message.

Link the local repository to a remote repository

First, create an empty repository on GitHub. Copy its URL, for example: https://github.com/username/my-project.git. Then run the following commands in your local project directory: git remote add origin https://github.com/username/my-project.git. This adds the remote repository and names it origin. git branch -M main = Renames your current branch to main. git push -u origin main = Uploads your local commits to GitHub and sets origin/main as the upstream branch, so future pushes are easier. Check the remote connection: git remote -v. This displays the remote repository URLs configured for fetching and pushing.
