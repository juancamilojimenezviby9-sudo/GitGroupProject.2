Git commands

Create a project locally

Open the terminal in VS Code and navigate to your project folder.

Initialize Git: git init → Turns the folder into a local Git repository.

Create your project files, then check their status: git status.

Stage and commit your files:
git add . → Stages all new and modified files in the current directory.

git commit -m "Initial commit" → Saves a snapshot of the staged changes.

Link the local repository to a remote repository

Create an empty repository on GitHub and copy its URL, for example: https://github.com/username/my-project.git.

Connect your local repository to GitHub:
git remote add origin https://github.com/username/my-project.git → Adds the remote repository and names it origin.

git branch -M main → Renames the current branch to main.

git push -u origin main → Uploads your commits to GitHub and sets the upstream branch for future pushes.

Verify the connection: git remote -v → Displays the configured remote URLs.

Update project

After making changes to your project, use these commands to save and upload your updates.

git status → Checks which files have changed.

git add . → Stages your changes.

git commit -m "Describe your changes" → Saves a snapshot of the staged changes.

git push → Uploads your commits to GitHub.
